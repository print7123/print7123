🚀 1단계: GitHub 저장소 생성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://github.com 접속 및 로그인
2. 우측 상단 "+" → "New repository" 클릭
3. 저장소 이름: onnuri-print-shop
4. Public 또는 Private 선택
5. "Create repository" 클릭
6. 저장소 URL 복사 (예: https://github.com/yourusername/onnuri-print-shop.git)


💻 2단계: Git 초기화 및 업로드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

────────────────────────────────────
1. "GitHub_배포_실행.bat" 파일 더블클릭
2. 저장소 URL 입력
3. 자동으로 업로드됨

────────────────────────────────────

🔐 GitHub 인증
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Push 시 인증 필요:
- 사용자명: GitHub 사용자명
- 비밀번호: Personal Access Token (비밀번호 아님!)

Personal Access Token 생성:
1. GitHub → Settings → Developer settings
2. Personal access tokens → Tokens (classic)
3. Generate new token (classic)
4. repo 권한 체크
5. 토큰 복사 (한 번만 표시됨!)


☁️ 3단계: Railway에 자동 배포
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://railway.app 접속
2. "Login" → "GitHub" 선택
3. "New Project" → "Deploy from GitHub repo"
4. onnuri-print-shop 저장소 선택
5. 자동으로 배포 시작! (2-3분 소요)


⚙️ 환경 변수 설정 (Railway 대시보드)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Railway → 프로젝트 → Variables 탭에서 추가:

DEPLOYMENT_MODE=production
DOMAIN=https://your-app.railway.app
HOST=0.0.0.0
PORT=5000
SECRET_KEY=your-random-secret-key-here
MAIL_SERVER=smtp.naver.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=print7123@naver.com
MAIL_PASSWORD=your-email-password
